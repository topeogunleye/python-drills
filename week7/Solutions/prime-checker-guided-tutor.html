Prime checker & prime sum

Learn how to decide whether a number is prime and build the running sum of primes up to N.

1. Understand the problem

Given integer N, print whether N is prime, list every prime from 2 through N, and print their total. A prime number is an integer greater than 1 whose only positive divisors are 1 and itself.

The range “up to N” includes N if it is prime. Values below 2 are not prime; the list and total are empty/zero when N is below 2.

Two jobs, two loops: To check N, test possible divisors using a while loop. To find all primes through N, visit each candidate and reuse the prime-check idea. Keep a running total instead of using sum().

2. Prerequisite idea: divisibility and square roots

A number d divides num evenly when num % d == 0; % gives the remainder. A divisor pair multiplies to the number. If a factor pair exists, at least one factor is no greater than the square root.

Instead of calculating a square root, compare d * d with the number. For 36, factor pairs include 2×18, 3×12, and 6×6; after 6, the paired factor would be smaller than the one being checked.

# Tiny unrelated modulo example

The required stopping test is i * i <= num. Do not import math.

3. How it works

First, inspect divisors of 10 in increasing order. Separately, candidates 2 through 10 are tested; prime candidates are added to the list and accumulator. Yellow marks a current candidate, blue marks a divisor being tested, green marks a confirmed prime.

4. Translate the idea into Python

Step 1: Handle numbers below 2. Prime numbers must be greater than 1.

Should the divisor loop run for 0 or 1?

Reveal answerNo. Neither is prime, so deal with them before testing divisors.

PseudocodeIf the number is less than 2, report not prime and do not search for divisors.

Step 2: Test possible divisors. Begin at the smallest divisor candidate and move one at a time using a while loop.

What condition tells you to stop searching without checking every number up to num?

Reveal answerContinue only while the divisor squared is less than or equal to the number.
Stuck?
NudgeUse the square-root insight from Section 2.
Bigger hintWrite the comparison without calling a square-root function.
PseudocodeWhile the current divisor squared is not past the number, check whether it divides evenly; if so it is not prime, otherwise advance the divisor. If no divisor is found, it is prime.

Step 3: Visit each candidate and accumulate. For candidates from 2 through N, check primality, keep prime candidates, and add them to a manually maintained total.

Which loop boundary ensures N itself gets tested?

Reveal answerUse an inclusive comparison so the candidate loop continues while candidate is less than or equal to N.
Stuck?
NudgeThe examples include N when it is prime.
Bigger hintInitialize the total at zero; update it only for prime candidates.
PseudocodeStart candidate at 2, an empty prime collection, and total zero. While candidate is no greater than N, test it; if prime, record it and add it to the total. Advance candidate each time.

Common symptoms

  • 0, 1, or negative N is called prime. Check the special case below 2 before divisor testing.
  • Perfect squares are marked prime. The boundary may stop too early; the square-root condition includes equality.
  • 2 is missing. Check whether the candidate loop includes its starting value.
  • N is missing from the list when N is prime. Check for an inclusive candidate-loop boundary.
  • The primality answer is right but the total is too small. Check the accumulator update for each prime, and avoid replacing it rather than adding.

6. Reflection

Prime candidates need no divisor checks beyond their square root. Use a while loop for the required divisor search. Test each candidate from 2 through N, collect prime values, and update a manual total.

Q1. Why does testing divisors beyond the square root add no new information?

RevealAny factor pair has at least one factor at or below the square root; the larger partner would already be paired with it.

Q2. What should the divisor loop conclude if it finds no exact divisor before its stopping condition?

RevealThe number is prime, provided the number was at least 2.

Q3. Why initialize the prime-sum accumulator to zero?

RevealZero is the neutral starting total; each confirmed prime is then added once.
