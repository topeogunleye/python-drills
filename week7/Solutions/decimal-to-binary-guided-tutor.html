Decimal to binary

See why repeated division by 2 reveals binary digits—and learn to assemble them in the right order.

1. Understand the problem

Input: a positive whole number written in decimal (base 10). Output: the same quantity written in binary (base 2), using only the digits 0 and 1.

For example, binary 1010 means 1 eight + 0 fours + 1 two + 0 ones, which is ten. Your program must build the result itself—not call bin() or binary string formatting.

Key idea: Dividing by 2 gives the next binary digit as the remainder (0 or 1). Integer division gives the smaller number to process next.

2. Prerequisite idea: quotient and remainder

For a whole-number division, the quotient is the whole-number result and the remainder is what is left. In Python, // gives the integer quotient, while % gives the remainder.

# Unrelated example
17 // 5  # quotient: 3
17 % 5   # remainder: 2

For binary conversion, repeatedly divide the changing number by 2. Each remainder is the rightmost (least-significant) binary digit. These digits arrive from right to left.

Step 3: Preserve order. The earliest remainder is the least-significant bit, so it belongs at the rightmost end.

If you discover digits 0, then 1, then 1, how do you arrange them as a binary number?

Reveal answerIn reverse discovery order: 110.
Stuck?
NudgeEach new remainder is more significant than the previous one.
Bigger hintPlace each new digit before the text already built.
PseudocodeFor each remainder, turn it into a character and add it to the beginning of the result text. When the quotient reaches zero, display the result.

Common symptoms

  • Digits are reversed. Remainders were appended at the end instead of placed at the front.
  • Only the last digit appears. The result text may be getting replaced each iteration rather than retained.
  • The loop never ends. Check that the working number is updated to its integer quotient every iteration.
  • Input 1 returns an empty string. Confirm the loop processes a positive value at least once.
  • There are unexpected digits beyond 0 and 1. Check that the remainder is calculated modulo 2.

6. Reflection

Each division by 2 reveals one binary bit as its remainder. Integer division moves toward zero. Remainders arrive least-significant first, so build the string from the front.

Q1. Why does each remainder have to be either 0 or 1?

RevealWhen dividing an integer by 2, the remainder is non-negative and less than 2.

Q2. Why is integer division needed for the changing value?

RevealIt gives the next whole-number quotient, which is the remaining higher-order part to convert.

Q3. Why prepend each new digit instead of appending it?

RevealThe first remainder is the rightmost bit; later remainders belong to its left.
