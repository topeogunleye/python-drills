Roman numeral to integer

Learn to read a numeral left to right, using a one-symbol look-ahead to spot subtraction pairs.

1. Understand the problem

You receive a string made from Roman symbols and return its integer value. The symbol values are stored in a dictionary: I=1, V=5, X=10, L=50, C=100, D=500, M=1000.

Most of the time, add a symbol’s value. If a smaller symbol comes immediately before a larger one (such as IV), subtract the smaller from the larger instead. Assume the input is a valid Roman numeral; the prompt does not ask you to validate Roman-numeral formatting.

Decision: Compare the current symbol’s value with the next symbol’s value. Look ahead only when a next symbol exists; otherwise a final symbol stands alone.

2. Prerequisite idea: dictionary lookup and indexing

A dictionary maps keys to values; here, symbol characters map to integer values. A string index selects one character: index 0 is first, and the last valid index is len(text) - 1. A look-ahead means safely checking the next character before deciding what to do.

3. How it works

Walk through MCMXCIV. Yellow is the current symbol; blue is the next symbol used for comparison; green marks the group being handled. A subtractive pair is processed together; otherwise, process one symbol and move one place.

RevealXL = 50 − 10 = 40, then I + I = 2; total 42.

Step 3: Choose pair or single-symbol handling. If current value is smaller than next, handle the pair as subtraction and advance past both. Otherwise add current value and advance one.

Why advance two positions after handling a subtractive pair?

Reveal answerBoth symbols have already contributed to the total, so neither should be processed again.
Stuck?

Bigger hintThe pair’s contribution is larger value minus smaller value.
PseudocodeCompare mapped current and next values if a next symbol exists. If current is lower, add the next-minus-current difference and move past both; otherwise add the current value and move to the next position.

Common symptoms

  • Subtractive examples are too large. Check whether you added both symbols instead of subtracting the smaller from the larger.
  • Normal sequences are too small. When current is larger or equal, add its value and advance one place.
  • The last symbol causes an indexing error. Check that look-ahead happens only when a next position exists.
  • A subtractive pair is counted twice. Advance past both characters after processing the pair.
  • Only one symbol type works. Check that the dictionary contains all seven mappings.

Q1. Why must the look-ahead index be checked before using it?

RevealAt the final character, index + 1 is outside the string.

Q2. What condition signals a subtractive pair?

RevealThe current symbol’s mapped value is smaller than the next symbol’s mapped value.

Q3. Why skip two positions after processing a subtractive pair?

RevealBoth symbols already contributed together, so revisiting either would count them twice.
