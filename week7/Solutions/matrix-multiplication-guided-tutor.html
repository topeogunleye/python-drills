Matrix multiplication

Learn how rows and columns meet to create each cell of a product matrix.

1. Understand the problem

A matrix is a rectangular grid of numbers. Multiplying matrices does not mean multiplying matching positions. Each result cell comes from pairing one row of A with one column of B, multiplying matching entries, then adding those products.

If A has m rows and n columns, and B has n rows and p columns, the product has m rows and p columns. The shared inside dimension n must match.

Compatibility rule: columns(A) = rows(B). If they do not match, no product matrix exists; this tutor assumes valid rectangular numeric matrices for calculation, and includes an incompatible test.

2. Prerequisite idea: row, column, index

Python represents a matrix as a list of rows, each row a list. So A[i][k] means row i of A, then column k in that row. Indices start at zero.

# Tiny unrelated example
labels = [["red", "blue"], ["green", "gold"]]
labels[1][0]  # "green": row 1, column 0

A dot product multiplies paired entries and adds those products. A running accumulator stores the partial total as the pairs are processed.

Practice by hand

P1. If A is 2×3 and B is 3×4, what shape is the result?

Reveal2×4: rows come from A, columns come from B.

P2. Compute one cell from row [2, 3] and column [4, 5].

Reveal2×4 + 3×5 = 8 + 15 = 23.

P3. Can a 2×3 matrix multiply a 2×4 matrix in that order? Why?

RevealNo. A has 3 columns but B has 2 rows; the shared dimensions do not match.

4. Translate the idea into Python

Step 1: Check dimensions. Identify row and column counts; verify the shared inside dimensions match.

Which two dimensions must be equal?

Reveal answerThe number of columns in A and number of rows in B.

PseudocodeMeasure A’s row count and column count, and B’s row count and column count. If A’s column count differs from B’s row count, report that multiplication is not possible.

Step 2: Visit each result cell. Choose one row of A and one column of B at a time; start a fresh total for that cell.

Which loop levels choose the result row and result column?

Reveal answerThe outer two loops choose one row of A and one column of B.
Stuck?
NudgeEach row/column pair creates exactly one output number.
Bigger hintThe output has A’s row count and B’s column count.
PseudocodeFor each row of A, prepare an output row. For each column of B, prepare a cell total and process the paired entries.

Step 3: Accumulate paired products. The third loop advances through A’s selected row and B’s selected column in sync.

After completing the inner loop, what should happen to the cell total?

Reveal answerAppend it to the current output row; after that row is complete, append the row to the result.
Stuck?
NudgeDo not reuse one cell’s total for another.
Bigger hintThe shared dimension determines how many matching pairs are accumulated.
PseudocodeFor each shared position, multiply the selected A entry by the selected B entry and add it to the cell total. Store the finished total in the row, and store completed rows in the result.

Common symptoms

  • Output dimensions are wrong. Check that result rows come from A and result columns from B.
  • Every output cell has the same value. Reset the accumulator for each new cell.
  • Works for square matrices but fails rectangular ones. Check which matrix supplies each loop bound.
  • Products pair the wrong entries. The inner index should move across A’s row and down B’s column together.
  • Only the last pair contributes. Check whether the cell total accumulates rather than gets overwritten.

6. Reflection

Check the shared dimensions before multiplying. Each output entry is one row-column dot product. The output takes its row count from A and its column count from B.

Q1. Why must A’s column count equal B’s row count?

RevealThose dimensions represent the entries paired in each dot product; they must have the same length.

Q2. What does the inner loop index represent?

RevealThe shared position: it selects one item across the chosen A row and the matching item down the chosen B column.

Q3. Why reset the accumulator for every output cell?

RevealEach cell is a separate dot product and must not include products from another row-column pair.
