Q21 — Fibonacci sequence & even sum

Refresh the ideas behind generating, filtering, totaling, and displaying a sequence—without being handed the program.

1. The concept

The Fibonacci sequence starts at 0 and 1; each later term is the sum of the two before it. A state pair is the pair of values you carry forward so you can produce the next term. A manual accumulator is a running total updated only when a condition is true.

For the transition, the old pair (0, 1) becomes (1, 1), then (1, 2). Both new values must be based on the old pair.

Common mistakes, by symptom

  • There is one extra term: the count tracks updates rather than terms emitted.
  • The sequence starts 1, 1 instead of 0, 1: the initial pair is off.
  • The even total is wrong for N = 8: the divisibility check or accumulator update is misplaced.
  • Reverse output is missing an end or separator: boundary formatting was not checked for N = 0 or N = 1.
  • Every term repeats: the state pair did not advance from its previous values.
