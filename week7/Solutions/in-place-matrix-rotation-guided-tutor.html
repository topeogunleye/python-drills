Rotate a matrix in-place

Understand the two safe transformations that turn a square matrix 90° clockwise without making another matrix.

1. Understand the problem

You receive an N×N square matrix: a list of N rows, each containing N values. Rotate its contents 90 degrees clockwise by changing the existing matrix. No new matrix should be created.

The prompt suggests two stages: transpose (swap rows and columns across the main diagonal), then reverse each row using swaps—not slicing.

In-place: update existing cells directly. A temporary value for a swap is okay; a second full matrix is not.

2. Prerequisite idea: indices and swaps

An item matrix[row][col] sits at one row and one column; both indices start at zero. A transpose moves cell (row, col) to (col, row). To avoid undoing a swap, visit only one half of the off-diagonal pairs.

To reverse a row without slicing, use two positions: left and right. Swap their values, move left inward and right inward, and stop when they meet or cross.

3. How the core idea works

Start with the provided 3×3 matrix. First transpose by swapping mirrored off-diagonal cells. Then reverse each row. Yellow and blue show a pair to swap; green marks the current changed pair or row.

The matrix remains N×N at both stages. The main diagonal cells (where row = column) do not move during transpose.

RevealFirst 8↔9, then 5↔2; result [9,2,5,8].

P3. What should happen to a 1×1 matrix after a 90° rotation?

RevealIt stays unchanged: the only value is on the diagonal and its row has nothing to swap with.

4. Translate the idea into Python

Step 1: Transpose off-diagonal pairs. Choose row and column indices so each pair is swapped once, without revisiting its mirror.

Why should a transpose loop skip cells where column is not greater than row?

Reveal answerTo avoid swapping the same pair twice and undoing the first swap; diagonal cells would only swap with themselves.
Stuck?
NudgeOnly one triangular half of the matrix contains unique mirrored pairs.
Bigger hintFor each row, begin column visits just beyond the diagonal.
PseudocodeFor each row index, visit only the column indices to its right. Swap each cell with its mirrored cell at the exchanged row and column indices.

Step 2: Reverse every row in place. For each row, swap its outside values, then move inward until the pointers meet or pass.

Why stop when the left and right positions meet or cross?

Reveal answerEvery needed pair has been swapped; continuing would swap pairs back or cross out of the row.
Stuck?
NudgeUse two positions that move toward the middle.
Bigger hintEach row needs its own left and right starting positions.
PseudocodeFor each row, set positions at its two ends. While left is before right, swap those entries, move left one step right and right one step left.

The prompt assumes an N×N matrix, so empty or non-square input handling is outside its stated constraints.

Common symptoms

  • Rotation is counterclockwise. Check whether you reversed rows after transposing; reversing columns changes the direction.
  • Transpose looks unchanged or pairs are restored. Check that each off-diagonal pair is swapped exactly once.
  • Odd-length rows have a broken middle. Stop the two-pointer swaps when pointers meet or cross.
  • A new matrix appears in the implementation. Confirm you only swap values in the original nested lists.
  • Rows change but columns seem wrong. Check whether the transpose step happened before reversing rows.

6. Reflection

Transpose swaps row and column positions across the main diagonal. Reversing each row then turns that transpose into a clockwise rotation. Both stages mutate the existing matrix through swaps.

Q1. Why is it safe to process only one half of the off-diagonal cells?

RevealEach cell and its mirror form one swap pair; visiting both would swap the values twice.

Q2. What does reversing each row contribute after transposition?

RevealIt changes the transposed arrangement into the clockwise orientation.

Q3. Why use two pointers instead of [::-1]?

RevealThe constraint forbids slicing, and swaps reverse the row in place without creating a reversed copy.
