Capitalize words & remove spaces

Practice scanning text one character at a time while building two different outputs.

1. Understand the problem

You receive a sentence. Build one version where the first ASCII letter of each word is uppercase, and a second version containing the same characters but no ordinary spaces.

A word start is the first letter position after a space. Punctuation or digits may appear before that letter, so the start marker should remain active until a letter is handled. The example uses ordinary spaces; this guide treats the space character " " as the separator.

Two output strings: Keep spaces in the capitalized sentence, but skip them when building the no-spaces version. Do not use .replace(), .title(), or .capitalize().

2. Prerequisite idea: characters and ASCII codes

A string can be visited character by character. ord(ch) gives a character’s numeric ASCII code; chr(code) turns a code back into a character. For ASCII lowercase letters, subtracting 32 gives the matching uppercase letter.

# Tiny isolated ASCII example
ord("b")       # 98
chr(98 - 32)   # "B"

A flag is a Boolean variable (True or False) that remembers a condition such as “we are still looking for this word’s first letter.”

If a character is a space, what should happen to the word-start flag?

3. How it works

Walk through the provided sentence. Yellow highlights the current character; blue marks a space; green shows a character changed to uppercase. The flag resets at each space and is cleared after the first ASCII letter of that word.

Every non-space character goes into both outputs. A space goes only into the capitalized output.

Practice by hand

P1. What should the two outputs be for "red blue"?

RevealCapitalized: Red Blue. No spaces: RedBlue.

P2. For "hi there" (two consecutive spaces), what happens to the word-start flag before “there”?

RevealIt becomes/remains on at each space, so the “t” in there is still capitalized. Removing spaces produces HiThere.

P3. For "42 cats", is the digit 4 capitalized? When is the flag cleared?

RevealNo. Digits are unchanged; under the stated ASCII-letter rule, the flag remains on until the first letter “c” is reached, which becomes “C”.

What should consecutive spaces do to the word-start flag?

Reveal answerEach space sets it to True; repeated spaces simply leave it True until a letter is processed.
Stuck?
NudgeSpaces separate words.
Bigger hintDo not add the separator to the no-spaces output.
PseudocodeFor each character, if it is an ordinary space, add it to the spaced output and reset the word-start flag. Otherwise continue to the letter/character handling and add the final character to both outputs.

Step 3: Capitalize only the first ASCII letter. While the flag is on, check whether the character is between lowercase a and z; if so, convert with ord, subtract 32, and use chr.

Why shouldn’t a digit at the beginning of a word clear the flag?

Reveal answerThe constraint says to capitalize the first letter, not the first character; the first ASCII letter may come later.
Stuck?
NudgeUse the stated ASCII range to distinguish letters.
Bigger hintAfter handling an uppercase or lowercase ASCII letter at word start, turn the flag off; leave it on for non-letters.
PseudocodeIf still at a word start and this character is an ASCII lowercase letter, convert it. Whether it was already uppercase or just converted, clear the flag once the first ASCII letter is reached; leave punctuation and digits unchanged.

Common symptoms

  • Every letter becomes uppercase. Check that conversion is limited to the first ASCII letter in each word.
  • The first letter after a space stays lowercase. Check that a space resets the flag.
  • Digits or punctuation prevent the later first letter from capitalizing. Keep the flag active until an ASCII letter is handled.
  • The no-spaces output still contains spaces. Check which output receives the separator character.
  • Already uppercase initials get mishandled. Clear the flag for an uppercase ASCII initial too, without changing its character.

6. Reflection

Scan one character at a time. A flag remembers whether the first letter of a word is still pending. Use the required ASCII conversion for lowercase initials. Build both strings separately so spaces can be retained in one and skipped in the other.

Q1. Why is a flag useful in this task?

RevealIt remembers whether the current character is still at the start of a word, even as the loop moves forward.

Q2. Why do consecutive spaces not cause a problem?

RevealEach one resets the flag to True; the next letter still sees that it is at a word start.

Q3. Why append each non-space character to both outputs?

RevealBoth versions retain the word characters; only the spaced version also retains separators.
